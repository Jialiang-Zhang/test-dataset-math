# 112-question curated benchmark

本目录包含从 `development/` 中筛选出的 112 道高难度数学题，用于按既定学科配额形成一个固定的评测子集。

- 保留源题原始 `idx`，便于追溯到 `development/` 中的原始记录。
- 每个 JSON 仍严格只有 `idx`、`problem`、`answer`、`subject`、`source` 五个字段。
- 选择时优先使用近期已经独立复核的高难题，避免基础题、明显模板换皮和语义重复。
